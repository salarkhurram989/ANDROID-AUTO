# 🚗 ANDROID-AUTO — AutoDash

A modern **standalone Android Auto-style dashboard** that runs directly in a browser or Android head unit — **no phone connection required**.

## 🌐 Live Website

👉 **[Open AutoDash](https://salarkhurram989.github.io/ANDROID-AUTO/)**

## ✨ Features

- 🚗 Speedometer and driving status
- 🧭 Compass / heading display
- 🗺️ Navigation-style dashboard
- 📍 Optional browser GPS location
- 🎵 Music player interface
- 🔊 Media controls
- 🌤️ Weather panel
- 🔋 Device battery display when supported
- 🕐 Live clock
- 📊 Trip meter
- 📱 Touch-friendly app shortcuts
- 🌙 Light / dark mode
- 📱 Responsive design for phones, tablets and car head units
- ⚡ No phone or Android Auto connection required

## 📂 Project Files

- `index.html` — dashboard structure
- `style.css` — interface and responsive design
- `script.js` — dashboard functionality

## 🚀 Run Locally

Download or clone the repository and open `index.html` in a modern browser.

## 📌 GitHub Pages

The project is designed to work with GitHub Pages. Enable Pages for the `main` branch and the website will be available at:

**https://salarkhurram989.github.io/ANDROID-AUTO/**

## ⚠️ Notes

This is a browser-based Android Auto-style interface. A normal website cannot directly control vehicle CAN-bus data, FM radio, steering-wheel controls, or phone calls without compatible hardware and browser/device support.

Live weather and full online maps require internet access. The main dashboard interface itself does not require a connected phone.
